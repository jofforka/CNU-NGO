# Quality Care for All Foundation — Lightweight Website V2

A simple static website designed for GitHub Pages.

## Included pages

- `index.html` — Homepage with donation, volunteer and partnership calls to action
- `volunteer.html` — Volunteer registration form
- `partner.html` — Partnership application form
- `news-events.html` — Links visitors to Instagram, Facebook and X/Twitter
- `assets/css/style.css` — Responsive lightweight styling
- `assets/js/main.js` — Mobile menu, date and email-form handling
- `assets/images/foundation-logo.jpg` — Website logo cropped from the supplied artwork

## Required edits before publishing

Search the project for these placeholders and replace them:

- `YOUR_DONATION_LINK_HERE`
- `YOUR_EMAIL@example.com`
- `YOUR_INSTAGRAM_LINK_HERE`
- `YOUR_FACEBOOK_LINK_HERE`
- `YOUR_X_LINK_HERE`

## Form behaviour

The volunteer and partnership forms create a prepared email using the visitor's email application.
This keeps the site free and lightweight without a database.

For a more reliable online submission system later, replace the forms with Google Forms,
Microsoft Forms, Formspree or another form service.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save and wait for GitHub to publish the site.
