# Quality Care for All Foundation — Version 4

A polished, lightweight, GitHub Pages-ready nonprofit website.

## Included pages
- Homepage
- Partners and partnership application
- Contact page
- Volunteer registration
- News & Events social links
- Privacy notice

## Main improvements
- New contact page
- Existing partner directory with logo, name and website link
- AI-generated healthcare imagery optimized as WebP
- Redesigned homepage and navigation
- Better mobile layout and accessibility
- Optimized images, CSS and JavaScript
- Improved forms and validation messages

## Replace these placeholders before publishing
- YOUR_DONATION_LINK_HERE
- YOUR_EMAIL@example.com
- YOUR_PHONE_NUMBER
- YOUR_OFFICE_ADDRESS
- YOUR_INSTAGRAM_LINK_HERE
- YOUR_FACEBOOK_LINK_HERE
- YOUR_X_LINK_HERE

- YOUR_SYNIA_WEBSITE_HERE

## Partner logos
The current partner logo cards are clean branded placeholders. Replace:
- assets/images/partners/cnu.webp
- assets/images/partners/so.webp
- assets/images/partners/saf.webp

with the verified official logos, keeping the same filenames, or update the HTML paths.

## Forms
Forms use the visitor's email application to keep the website free and lightweight.
For direct online submission, connect them later to Formspree, Google Forms, Microsoft Forms or Google Apps Script.

## GitHub Pages
Upload all files to a repository, then enable Pages from the main branch and root folder.
